# Heidrun organization website

This repository holds the homepage of the Heidrun organization, published at **https://heidrun-org.github.io/**.

The homepage introduces the organization and links to the Heidrun application, documentation, downloads, and source code.

## Update the website

Edit [index.html](index.html) and commit the change to `main`. GitHub Pages publishes the website from the root of the `main` branch.

The page contains its own styles and requires no package installation or build command. Open `index.html` in a browser to preview changes locally. The Heidrun logo is loaded from the public Heidrun application repository.
